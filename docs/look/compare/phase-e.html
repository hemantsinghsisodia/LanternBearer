Phase E: before and after

Left is the Phase E starting point (baseline/2026-10-06-e-before), right is the Phase E result (baseline/2026-10-06-e-after). Same shot lists, 1920x1080, JPEG, Low and Ultra, captured in the editor Game view. World shots are expected to be unchanged: Phase E touches menus and UI only.

What changed in Phase E:

  • Main menu is a ledger: an ink panel with Play, Keeper's Log, Settings and Quit, and an island list. Each row shows beacon roofs (amber for pages found) with a found/total count such as 7/9, the island name and best time. Difficulty is a 3-way switch.
  • Settings screen with Display (brightness calibration, resolution, window mode), Graphics, Audio (Master, Music, Effects, Ambience), Accessibility and Controls. Opens from the main menu and from pause.
  • Keeper's Log is a two-page parchment book with a ribbon, Previous/Next, and torn-page placeholders.
  • Pause is a themed ink and brass panel (Resume, Restart, How to Play, Settings, Main Menu).
  • Accessibility: text size 100/115/130% and a reduce-flashing option.
  • Brightness works on every graphics preset.

Capture note: in the automated Ultra "mainmenu" screen the Keeper's Log is still open from the Low pass, so that frame shows the Log. The Ultra main menu is shown from the Task 5 capture in the extra section below.
