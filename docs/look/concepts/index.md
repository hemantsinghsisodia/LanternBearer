# Lantern Keeper: Phase A concept boards

Rough illustrations from the 2026-10-03 art-direction brainstorm. Each board is a standalone HTML page (open it in any browser, no server needed). The approved option carries an amber "Chosen" badge. The boards are direction sketches, not final art.

Rules and rationale: [Art direction design spec](../../superpowers/specs/2026-10-03-art-direction-design.md), Section 1.

| Board | Decision | Rationale |
|---|---|---|
| [art-style.html](art-style.html) | Stylized painterly night | Soft gradients and simple silhouette shapes; surfaces are painted or flat, never photographic. |
| [darkness.html](darkness.html) | Balanced darkness | Deep-blue silhouettes outside the lantern, full warm colour inside it, and pale moonlit rims keep hazards readable. |
| [island-palettes.html](island-palettes.html) | All four island palettes approved | Each island gets its own cool night palette and mood; lantern amber stays the same everywhere. |
| [keeper-silhouette.html](keeper-silhouette.html) | Hooded wanderer | Deep hood, torn-hem cloak and satchel with the lantern held out read clearly as a silhouette. |
| [lantern.html](lantern.html) | Iron storm lantern | The square iron frame, four panes, peaked roof and ring handle are crisp at distance and double as the HUD fuel icon. |
| [moths.html](moths.html) | Dusty moth | Dim grey-blue far away, warm-lit up close, and no competition with the glowing fireflies. |
| [shades.html](shades.html) | Smoke wraith | An ink-dark, ragged body that breaks into smoke is menacing and takes a pale-blue outline in lightning. |
| [beacons.html](beacons.html) | Keeper's lamp-post | A big storm lantern on a dry-stone cairn ties beacons to the lantern's shape language. |
| [ui-theme.html](ui-theme.html) | Forged iron and amber | Ink panels with thin brass lines, amber for the primary action, and Cormorant Garamond, Spectral and Inter type. |
