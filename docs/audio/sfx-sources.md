## Total size

Whole-pack downloads, each counted once: K1 0.83 + K3 0.69 + R1 2.4 + R2 1.9 + R3 1.8 + R4 2.3 + F1 0.48 + F2 0.02 + B1 0.11 + W1 1.99 + FS1 1.0 + FS2 9.6 + FS3 0.92 + FS4 0.41 + FS5 1.4 + FS6 10.3 + FS7 1.2 + FS8 2.6 + FS9 3.2 + FS10 2.7 = about 45.9 MB, plus Kenney Impact Sounds (K2), whose size the page does not show (its zip is expected to be a few MB).
The final game will keep only the chosen files, converted to OGG, so the shipped size will be much smaller.
