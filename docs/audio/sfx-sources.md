# Phase G effects source list

All sources below were checked on their own page. Licence column shows the text the page gives. Nothing has been downloaded.
Pack contents are known only from page descriptions, so the exact file for a cue is chosen after download (notes say what to look for).
"Alt" entries are fallbacks if the main pick sounds wrong.

Freesound items FS1-FS10 are not used (login required). The chosen non-Freesound sources are in the Addendum table and the cue table.

## Total size

Whole-pack downloads, each counted once, no Freesound: K1 0.83 + K3 0.69 + R1 2.4 + R2 1.9 + R3 1.8 + R4 2.3 + F1 0.48 + F2 0.02 + B1 0.11 + W1 1.99 + RL 2.7 + N1 0.18 + N2 5.9 + N3 0.15 + N5 2.8 + N6 0.25 = about 24.5 MB, plus Kenney Impact Sounds (K2), whose size the page does not show. Alternates (N2b, N4, Strong Wind #1/#2, Long-Eared Owl) are not counted.
The final game will keep only the chosen files, converted to OGG, so the shipped size will be much smaller.
