# Phase F2: In-game HUD and Cards — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the plain-text in-game HUD and its cards with the forged-iron and amber design, and split `HUD.cs` into focused components. Gameplay is unchanged.

**Architecture:**
- Pure display maths lives in the Logic assembly (`HudMath`).
- Small HUD components (`LanternKeeper.UI` kit style, Assembly-CSharp) each own one widget. They are built into one `GameHud.prefab` by the Phase E `UIBuilder`, and placed on every island by an idempotent installer.
- `HUD.cs` shrinks to a coordinator. It reads `GameManager`, `Lantern` and `PlayerController`, then pushes values into the components.

**Tech Stack:** Unity 6 (6000.6.3f1), URP Deferred, uGUI, TextMeshPro, the Phase E UI kit (`InkPanel`, `ThemedButton`, `ThemedLabel`, `TextScaler`), NUnit EditMode and PlayMode tests, Unity MCP.

**Spec:** `docs/superpowers/specs/2026-10-08-hud-f2-design.md`

## Global Constraints

**Style**
- Forged iron and amber, built from `UITheme`.
- Fonts: Cormorant for titles, Spectral italic for flavour text, Inter for UI text and numbers. No LiberationSans or TMP default font.

**Signal colours** (exact, from `LookPalette`)

| Colour | Value | Meaning |
|---|---|---|
| Amber | `#FFB15C` | fuel, lit roofs, shield |
| Violet | `#B48CFF` | moth drain |
| Lightning blue | `#BCD2FF` | storm |
| Firefly green | `#B8FFB0` | firefly pickups only |

**Readability**
- HUD text is at least 18 px at 1080p at text scale 1.0, and follows `TextScaler`.
- Every HUD element has an ink backing or a soft text shadow.
- At 1.3 scale nothing may overflow at 1920×1080 or 1280×720.

**Gameplay and data**
- No change to `GameManager`, `Lantern` or `PlayerController` rules, timing or values.
- The HUD only reads state. The only edits allowed in gameplay files are deleting the dead F1 lookups named in Task 5.

**Fuel gauge rules** (from the spec)
- Flame turns redder below fuel 0.30.
- Soft pulse below 0.15.
- Pulse rate halves when Reduce flashing is on (`SettingsMath.FlashCap`-style flag from `UserSettings.ReduceFlashing`).
- Fuel-change flash shows "−N" or "+N" for about 1 s.

**Cards**
- Intro card fades over 0.3 s, using unscaled time.
- Win panel title: "The shore is lit". Buttons: Next island (primary, hidden on the last island), Retry, Main Menu.
- Lose panel title: "The flame went out". Flavour line: "Your lantern went dark." Buttons: Retry (primary), Main Menu.
- The first button gets focus. Keyboard and gamepad work.

**Toasts**
- Queue and never overlap.
- Log-page toasts are parchment-tinted.

**Process**
- No full `IslandBuilder` level rebuilds. Use `UIBuilder` and installers, with prefab IDs kept stable by `PrefabIdStabilizer`.
- Terrain stays hash-identical.
- Never revert, edit or commit `Assets/Settings/UniversalRenderPipelineGlobalSettings.asset`.
- Revert noise: TMP font SDF assets, `ShadeBody`/`Smoke` mats, `ProjectSettings/*`, `EditorSettings`, Look volumes, and scenes that only re-serialised. Check with `git diff --ignore-space-at-eol --stat`.
- Leave `Assets/Settings/Build Profiles/` untracked and untouched.
- Restore `LanternKeeperGraphics` to 0 after captures.
- EditMode UI tests use `DestroyImmediate` plus `Undo.ClearAll()` in teardown, and new classes are run alone first. If Unity crashes, stop.
- A single Island 4 `BeaconReachability` failure that passes on rerun is a known flake (user ruling).
- If the MCP drops for more than about 2 minutes, Unity closes, or a git action is denied, stop and report.

**Performance**
- Measured only in Task 6: one probe pass per island, Low and Ultra, against `docs/look/perf/2026-10-07-phase-f1.md`. Limit: +0.3 ms average.
- If it fails, stop and report. No reruns and no A/B runs without the user's go-ahead.

**Model split:** implementers and reviewers use Sonnet (AGENTS.md).

**Test access:** Assembly-CSharp types are reached by reflection (`Type.GetType("LanternKeeper.X, Assembly-CSharp")`). Pure maths lives in Logic.

## Review Focus
1. **Fuel at exactly 0 and at full, plus rapid repeated fuel changes** (moth drain ticking every frame). The gauge must not jitter or stack overlapping "−N" flashes; it coalesces them into one running total for about 1 s. Test: `HudMathTests.FlashCoalescesRapidChanges` (Task 1).
2. **An island with more beacons than the roof row fits** (Island 3 and 4 have 9), and 130% text. The roofs must fit inside the panel without overlapping the fuel bar. Test: `UiLayoutTests.HudPanelFitsNineRoofsAt130` (Task 5).
3. **Win or lose while a toast, the intro card or pause is showing.** The result panel takes focus and sits on top. Toasts are cleared, and pause cannot open over it. Test: `ResultPanelTest.ResultWinsOverToastAndPause` (Task 4).
4. **Restart from the lose panel, then play again.** HUD state (roofs, timer, flashes, toasts) resets to the new round, with no stale lit roofs. Test: `HudLiveTest.RetryResetsHud` (Task 3).
5. **Moth count changing from 3 to 0 while in a safe ring.** The moth icon hides and the shield shows, with no frame where both the old count and the shield overlap wrongly. Test: `HudMathTests.DrainIconsFromState` covers the table (Task 1).

### Task 1: Before capture and HUD maths

**Files:**
- Create: `Assets/Game/Scripts/Logic/HudMath.cs`
- Test: `Assets/Game/Tests/EditMode/HudMathTests.cs`
- Capture: `docs/look/baseline/2026-10-08-f2-before/`

**Interfaces (all in `HudMath`, static):**
- `struct FlameLook { public float Scale, Glow, Redness, Pulse; }`
- `FlameLook Flame(float fuel01, float time, bool reduceFlashing)`
  - `Scale` = 0.35 + 0.65 × fuel01.
  - `Redness` = 0 at 0.30 and above, rising to 1 at 0.
  - `Pulse` = 0 at 0.15 and above. Below that it is a 0..1 sine at 2 Hz, or 1 Hz when `reduceFlashing` is true.
- `struct DrainState { public int MothsDraining; public bool InSafeLight; public bool Sprinting; public float DrainRelative; }`
- `struct DrainIconsView { public bool Moth; public int MothCount; public bool Shield; public bool Ember; public bool Multiplier; public string MultiplierText; }`
- `DrainIconsView DrainIcons(DrainState s)`
  - The moth icon shows when `MothsDraining > 0`.
  - The shield shows when `InSafeLight`.
  - The ember shows when `Sprinting && !InSafeLight`.
  - The multiplier shows when `DrainRelative > 1.05f && !InSafeLight`, formatted `"×" + DrainRelative.ToString("0.0")`.
- `class FuelFlash` (pure accumulator):
  - `void Add(float delta, float now)`: coalesces changes within 1 s into one running total.
  - `bool Visible(float now)`: true for 1 s after the last change.
  - `string Text`: "−12" or "+5", rounded to the nearest int; the minus sign is U+2212.
