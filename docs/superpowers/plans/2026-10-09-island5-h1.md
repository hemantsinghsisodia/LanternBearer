# Island 5 "The Great Light", H1 (Playable Island): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Island 5 playable from start to finish:
- a generated spire mountain with 8 beacons and 4 required light-bridge gaps (optional bridges dropped 2026-10-09);
- height rings whose hazards ratchet up and never come back down;
- thin air on the high ring, and a summit gate;
- the great lamp, which for now runs the existing dawn and win;
- unlock from Island 4, its own look and music, Log pages, and a placeholder ending.

**Architecture:**
- **Pure Logic.** `SpireLayout` holds the geometry: spiral, rings, gaps and beacon slots. `RingLogic` holds the bands, the ratchet, the tension floors and the thin-air values.
- **Island builder.** A new `spire` mode in `IslandBuilder` sculpts the terrain and places the beacons, bridges and great lamp.
- **Runtime components.** `LightBridge`, `RingZones`, `ThinAir`, `SummitGate` and `GreatLamp`. They drive the existing systems (`Tide`, `Wind`, `Lightning`, `ShadeSpawner`, `MothSpawner`, `Lantern`, `MusicDirector`) through small enable and intensity hooks.

**Tech Stack:** Unity 6000.6.3f1, URP, C#, NUnit (EditMode and PlayMode), Unity MCP, ffmpeg and Python for audio, WebFetch for music research.

**Spec:** `docs/superpowers/specs/2026-10-09-island5-great-light-design.md`. Sections 1–4 and 6 are H1; the H2 items (lighthouse model, finale, credits, finale cue) are excluded.

## Global Constraints
- **Gameplay on Islands 1–4 is unchanged.** The only exception is Island 4's `nextLevelScene`, which becomes `"Island5"`. The terrain and alphamaps of Islands 1–4 must stay byte-identical (check by hash). Do not rebuild Islands 1–4.
- **Island 5 shape:**
  - island radius about 45 m;
  - summit about 40 m;
  - the ring bands are fixed:

    | Ring | Height |
    |---|---|
    | Low | 0–10 m |
    | Mid | 10–25 m |
    | High | 25–38 m |
    | Summit | above 38 m |

  - the spiral path goes round about 1.75 turns from the beach spawn to the summit.
- **Beacons and gaps:**
  - 8 beacons, all of which must be lit, plus the great lamp;
  - 4 required gaps (flooded inlet, tidal chasm, broken stair, summit span);
- **Bridges:**
  - the beam arc takes about 1 s;
  - the bridge grows from both ends over about 1.5 s;
  - it is walkable **2.5 s or less** after the near beacon is lit;
  - it has invisible rails;
  - it counts as **safe light**: the drain is the safe-ring rate, moths do not follow, and Shades cannot cross;
  - once built it is permanent;
  - the summit span forms only when all 8 beacons are lit.
- **Ring hazards** (the ring reached is ratcheted; the hazard level never goes down):

  | Ring | Hazards |
  |---|---|
  | Low | tide in 2 inlets, 3–4 moths, dense fireflies |
  | Mid | wind (gentler than Island 4), 2 Shades on the cliff path, fewer fireflies |
  | High | lightning, plus **thin air**: lantern radius ×0.80, drain ×1.15 |
  | Summit | calm |

- **Music:**
  - tension floor 0 / 0.3 / 0.6 for low / mid / high (ratcheted);
  - at the summit, track and tension fade to the summit hush;
  - in H1, lighting the great lamp plays the existing Stinger.Win, then the existing dawn and win.
- **Labels:** `displayName` "Island 5", `islandTitle` "The Great Light". 3 new Keeper's Log pages and intro lines.
- **Art direction (Phase A):** the warm/cold rule applies to lights only, and the signal colours are amber `#FFB15C`, core `#FFD38A`, violet `#B48CFF`, blue `#BCD2FF` and green `#B8FFB0`. Bridges use amber and core.
- **Music sourcing:** CC0 only, from OpenGameArt, Kenney or BigSoundBank. No Freesound. The user picks from a shortlist, and only the picks are downloaded. Loudness targets: music −23 LUFS; tension and hush also −23. True peak ≤ −1 dBTP.
- **Protected files:**
  - Never edit, revert or commit `Assets/Settings/UniversalRenderPipelineGlobalSettings.asset`.
  - Leave `Assets/Settings/Build Profiles/` untracked.
- **Noise:** revert with `git checkout`: TMP font SDF assets and the Liberation fallback, `ProjectSettings/*`, `EditorSettings`, light-data-only scene noise, and `Assets/InitTestScene*.unity`. Restore PlayerPrefs `LanternKeeperGraphics` to 0. Don't touch `LanternKeeperIntro_*`.
- **Perf:** one probe pass on Island 5 at Low and Ultra. The limit is +0.3 ms over the Phase G average of Islands 1–4 (`docs/look/perf/2026-10-08-phase-g.md`, re-measure table). If anything fails, report the numbers before investigating.

## Review Focus
1. **The keeper walks back down after reaching the high ring.** Lightning and thin air must stay on, and the music floor must stay at 0.6. Test: Task 4 `RatchetSurvivesDescent`.
2. **The keeper stands on a bridge while a Shade chases.** The Shade must not step onto the bridge, and drain must be the safe rate. Test: Task 3 `BridgeBlocksShadeAndIsSafe`.
3. **Retry mid-climb.** Rings, bridges, ratchet and music floor must all reset to their starting state. No static state may leak. Test: Task 4 `RetryResetsRingsAndBridges`.
4. **The keeper lights a near beacon, then immediately walks onto the forming bridge.** No falling through: the collider exists only once the bridge is complete, and a half-grown bridge cannot be walked. Test: Task 3 `CannotStepOntoGrowingBridge`.
5. **Fewer than 8 beacons lit at the summit.** The span must not form and the great lamp must not be reachable. Lighting the 8th beacon from below must still open it. Test: Task 3 `SummitSpanWaitsForAllEight`.

**Files:**

**Interfaces (produces):**
```csharp
public enum Ring { Low = 0, Mid = 1, High = 2, Summit = 3 }
public static class RingLogic
{
    public const float LowTop = 10f, MidTop = 25f, HighTop = 38f;
    public const float ThinAirRadius = 0.80f, ThinAirDrain = 1.15f;
    public static Ring Classify(float heightAboveSea);           // bands above; boundaries go to the upper ring
    public static Ring Ratchet(Ring reached, Ring current);       // max(reached, current) — never lower
    public static float TensionFloor(Ring reached);               // Low 0, Mid 0.3, High 0.6, Summit 0.6
    public static bool ThinAirActive(Ring reached);               // High or Summit
}
public struct SpireGap { public Vector2 nearXZ, farXZ; public bool required; public int nearBeacon, farBeacon; }
public static class SpireLayout
{
    public const float Radius = 45f, SummitHeight = 40f, Turns = 1.75f;
    public static Vector2[] SpiralPath(int samples);              // beach (angle 0, r≈Radius-4) → summit (r≈3)
    public static float PathHeight(float u01);                    // smoothly 0.5 m → 38.5 m along the path
    public static Vector2[] BeaconXZ();                           // exactly 8, ordered up the spiral
    public static SpireGap[] Gaps();                              // 4 required (indices per spec order)
    public static Vector2 LampXZ();                               // summit centre
}
```
Implementation notes:
- Deterministic and seed-free, so the layout is fixed by design.
- Beacon slots are spread evenly along the spiral parameter, skipping the gap spans.
- **Required gaps:** gaps 1–3 cut across the spiral path at u ≈ 0.18, 0.42 and 0.66. Gap 4 is the final span to the summit plateau. Each gap is 6–9 m wide in XZ.

  - `TensionFloors`: 0, 0.3, 0.6, 0.6.
  - `ThinAirOnlyHighUp`.
  - `SpiralStartsAtBeachEndsAtSummit`: the first point is at r ≥ 40, the last is within 4 m of `LampXZ`, and PathHeight(0) < 1 and PathHeight(1) > 38.
  - `EightBeaconsOrderedUp`: 8 slots, and PathHeight at their u values is strictly increasing.
  - `FourRequiredGaps`: required widths 6–9 m; every gap references valid beacon indices; gap 4's far side is within the summit plateau radius (6 m) of `LampXZ`.
