# Phase H3 (Playtest Feedback, Island 5 Challenge, Dawn Progression): Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Act on the H2 playtest feedback:
- fix the menu lit count;
- replace the horizon lighthouse with the dark Great Light;
- end the Island 1–4 wins in a partial pre-dawn;
- swap the beacon fire whoosh;
- make Island 5 a real finale with a rising storm, hunting lightning and scarce fuel.

**Architecture:**
- **Pure Logic first:** `StormSurgeLogic`, `PreDawn`, `LitCount`, all EditMode-tested. Thin runtime components sit on top.
- **Scene changes** go through editor installers. Islands are never rebuilt, so the Island 1–4 terrain hashes hold.
- **Island 5 hazards** are added to `Island5PostSteps`.

**Tech Stack:** Unity 6000.6.3f1, URP, C#, NUnit (EditMode and PlayMode), Unity MCP, ffmpeg and Python for audio, WebFetch for the CC0 shortlist.

**Spec:** `docs/superpowers/specs/2026-10-13-h3-polish-design.md`, with `2026-10-09-island5-great-light-design.md` as its parent.

## Global Constraints
- **Islands 1–4** keep their gameplay and byte-identical terrain (the hash tests). The only changes allowed are the win look (pre-dawn) and the horizon lighthouse. Never rebuild them; use installers.
- **Pre-dawn reach:** 0.25 / 0.45 / 0.65 / 0.85 for Islands 1 / 2 / 3 / 4. The Island 5 finale keeps the full sunrise.
- **Rising storm (Island 5):**
  - starts 45 s after the first beacon is lit;
  - a steady climber stays about 8–12 m ahead;
  - −3 m per beacon lit;
  - capped at the summit plateau base;
  - inside it: drain ×4, and beacon safe rings don't protect;
  - bridges still count as ground;
  - HUD text `"Storm rising: N m below"`.
- **Hunting lightning (Island 5, High and Summit rings, before the lamp):**
  - one strike every 6–10 s;
  - it targets a point 2–4 m from the keeper's predicted position;
  - a 1.0 s warning ring comes first;
  - a hit costs 15% of max fuel and knocks the keeper back;
  - bridges and lit-beacon safe rings are immune.
- **Scarce fuel (Island 5):** firefly swarms ×0.5. Each beacon lit refunds 20% of max fuel.
- **Whoosh audio:**
  - CC0 only, from Kenney, OpenGameArt or BigSoundBank. No Freesound.
  - The user picks; download only the pick.
  - −18 LUFS, true peak ≤ −1 dBTP.
- **Protected files:**
  - Never edit, revert or commit `Assets/Settings/UniversalRenderPipelineGlobalSettings.asset`.
  - Leave `Assets/Settings/Build Profiles/` untracked.
  - Don't commit the `ProjectSettings.asset` build side effect.
- **Noise:**
  - Revert with `git checkout`: the TMP font SDF assets, the Liberation fallback, EditorSettings and `InitTestScene*`.
  - Never `git checkout` scenes or source.
  - Never text-edit a loaded scene.
  - Editor PlayerPrefs `LanternKeeperGraphics` ends at 0.
  - Don't touch the `LanternKeeperIntro_*` keys or the player registry.
- **Perf:** one probe pass on Island 5, against the H2 numbers (Low 2.85 ms, Ultra 10.03 ms). The limit is +0.3 ms. If it fails, report before investigating.

## Review Focus
1. **A player waits at the bottom, or walks back down, after the storm starts.** It must catch them, drain them fast and not softlock them. They can still climb out. Test: Task 6 `CaughtKeeperCanClimbOut`.
2. **Lightning on a bridge or in a lit-beacon ring.** It must never hit there. Test: Task 7 `NoStrikeInsideShelter`.
3. **Retry during the storm or after a strike.** The surge, strike timers and fuel all reset, and nothing static leaks. Test: Task 6 `RetryResetsSurge`.
4. **Reduce Flashing on.** The strike warning and flash respect `UserSettings.ReduceFlashing`. Test: Task 7 `StrikeRespectsReduceFlashing`.
5. **The Island 1–4 win with pre-dawn.** No sun disc, the result panel still shows, and the Island 5 finale is unaffected. Test: Task 4 `PreDawnNeverShowsSun`.

public static class StormSurgeLogic {
